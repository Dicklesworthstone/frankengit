Move Git history without losing its identity

Export a pinned snapshot or import a full Git bundle. Git objects and direct refs are transferred; issues, reviews, credentials and the default HEAD are not. Every publication uses the existing native authority.

Source-read is required for selection/export, source-write for import/fetch, and outcomes-read for recovery. Deployment switches and native policy still apply. Tokens remain in page memory only. Use HTTPS outside trusted loopback.

Connect an explicitly scoped repository token.

Export this snapshot

Downloads appear only after complete bounded transfer and identity checks. A Git bundle is not a forge backup or repository capsule.

Inspect a full bundle

Self-contained v2/v3 bundles only. Header and pack-checksum validation is not object or closure admission. The native service verifies objects and policy before publishing. Prerequisite/filter bundles are not accepted by this profile.

Explicit fetch destinations

Use “Map this reference” for each source to import. Supply a complete destination ref and either absent or its exact old native OID. No destination or old tip is inferred; at most 64 mappings. One source may be mapped to several distinct destinations.

Or import all advertised direct refs

All destinations must be absent. No existing ref is overwritten and advertised HEAD is not installed. This operation supports at most 64 direct refs; use mapped fetch for a subset of larger bundles.

Exact pending publication


      
Save the recovery receipt before sending. It contains private bundle bytes and exact mappings, but not the token. A timeout, disconnect or missing outcome never proves non-commit. An exported receipt may be sent by another session and cannot be discarded as unsent.

      
      
      
    

    

      
Recover an interrupted transfer

      
Connect the original valid credential, then restore its saved receipt. A successful ref listing is not required for recovery. Restore checks the exact request commitment but never dispatches it. Keep the credential bound to the original principal.
