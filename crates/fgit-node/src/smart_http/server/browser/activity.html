Connection

The collaboration feed includes milestones, discussions, PR conversations and review votes only when your token grants access. Disconnect to change this selection; start at cursor 0 to backfill a different profile.

Credentials stay in memory and are cleared on disconnect or navigation. The server authenticates each read independently; write or source-read grants do not imply activity access.

Read activity

Load uses the entered cursor and size. Next preserves the selected snapshot and size. Refresh reads after the last successful watermark at a newly observed head, including after a snapshot conflict. Load and Refresh may wait at an empty tail for the chosen duration. Any cursor progress returns immediately, even when filtered. Cancel stops the read. Nothing polls or retries automatically.
