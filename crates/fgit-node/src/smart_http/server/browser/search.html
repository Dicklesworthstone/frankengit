Search source. Inspect exact bytes.

Search one repository snapshot using literals, a shared batch of terms, bounded native byte regexes, or persisted whole-word indexes. Open a result to verify its complete file against the returned native blob identity.

The token stays in page memory, is cleared from its input on Connect, and is discarded on disconnect or page exit. HTTPS is required outside loopback. No writes or automatic retries are available here.

Examples: \b(struct|enum)\b or ^pub\s+fn\s+\w+. Regexes do not cross LF; CR remains a byte. Lookaround, backreferences, Unicode properties and lazy quantifiers are not supported.

Indexed words are case-folded ASCII tokens, not substrings, phrases, regexes or symbols. An operator must build an index first. Strict mode requires its exact source snapshot. Explicit revalidation permits changed repository metadata only for the same native commit and tree, and displays both source snapshots. No query builds, refreshes or falls back to scanning. Continued pages and file navigation pin the current validated source and original index; release a moved snapshot explicitly.
