Search source. Inspect exact bytes.

Search one repository snapshot using literals, a shared batch of terms, bounded native byte regexes, persisted whole-word indexes, indexed Rust declarations, or a combined content/path/declaration view. Open a result to verify its complete file against the returned native blob identity.

The token stays in page memory, is cleared from its input on Connect, and is discarded on disconnect or page exit. HTTPS is required outside loopback. No writes or automatic retries are available here.

Examples: \b(struct|enum)\b or ^pub\s+fn\s+\w+. Regexes do not cross LF; CR remains a byte. Lookaround, backreferences, Unicode properties and lazy quantifiers are not supported.

Indexed words are case-folded ASCII tokens, not substrings, phrases, regexes or symbols. An operator must build an index first. Strict mode requires its exact source snapshot. Explicit revalidation permits changed repository metadata only for the same native commit and tree, and displays both source snapshots. No query builds, refreshes or falls back to scanning. Continued pages and file navigation pin the current validated source and original index; release a moved snapshot explicitly.

Queries read existing native Rust declaration tables, not a compiler-resolved symbol graph. Macro expansion and cfg evaluation are not performed. An operator must build a symbol index at the exact source snapshot; lexical revalidation does not apply. No query builds, refreshes or falls back to scanning. Results are a bounded prefix without server pagination: narrow a truncated query. Source-byte limits bound the referenced tables; the native index payload ceiling is 32 MiB.

Combined search reads existing content and path indexes, plus declarations when a separate name is supplied, in one native Initial request. All contributing channels must match one exact source snapshot; lexical revalidation is not used. Work and payload limits are shared, not renewed per channel. Optional missing/stale declarations are explicitly unavailable, never empty success; a retained symbol checkpoint still requires a resolvable index. No query builds, scans, ranks or retries. There is no combined continuation. Bytes per file limits navigation only in this mode.
