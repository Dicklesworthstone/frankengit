Repository merge queues

Inspect the recorded queue order and prepare exact changes. Enqueueing, reordering, and reviewing a PR leave its target branch unchanged. A separate committed landing updates the target and merges the PR.

Queue reads, queue management, PR reads, and queue landing have independent grants. Recovery-only mode accepts a credential for looking up the original principal's outcome; it permits no reads, preparations, or sends. Credentials stay in memory.

Connect an explicitly scoped token to begin.
